BIM Semantic 的表格结构特征

数据快照：2026-10-14 · 制图：2026-10-27 · 215 个模型 · 93,359 个构件

用三项定量证据支撑属性级表示的设计动机：固定列表格的稀疏性、每个构件拥有不同数量的属性、属性在模型之间的低共享性。

统计阶段：以下是当前审计快照的描述统计，尚未全面统一同义字段，也未完成全部模板内容清理。它们不能标作“最终清洗后的 WP1 表格”。所有图使用非空字段口径，名称、引用和未定义占位文本仍会计入；0 和 false 保留。

主图：三个面板分别证明什么？

__MAIN_FIGURE__
  1. A：非空比例。全局字段展开后，非空单元格仅占 0.46%。按构件类别各自建表后，比例仍约为 0.79%–7.33%。因此稀疏并不只是把墙、门、窗混在一张表中造成的。每条的分母不同：全局使用全部字段并集，各类别使用本类别字段并集。
  2. B：属性数量变化。每个箱体是该类全部构件的属性数量分布，不是先计算模型中位数。箱体覆盖中央 50%，中线为中位数，须按标准 1.5 倍四分位距规则延伸，圆点为须外观测。横轴使用对数坐标，刻度仍标实际属性数量，全部观测均被保留。
  3. C：模型之间的共享程度。每个“构件类别＋属性名”组合统计一次。只要一个模型中有一个该类构件填了该属性，就算出现于该模型。全部 5,392 个组合中，4,141 个只出现在一个模型，占 76.8%。该图不把同一字段在多个构件上的重复出现计成多个字段。

A 的“空白”可能来自不适用或未提供，不能直接解释为信息缺失或质量低。B 的箱线图异常点是统计上的须外点，不代表这些构件的数据错误。C 的稀有字段可能有用，也可能是尚未统一的同义写法。

敏感性检查：排除 model_6 后是否仍然成立？

model_6 包含 1,021 个构件，但贡献了大量局部字段。删除它后，对剩余 214 个模型、92,338 个构件重新确定字段并集，全局字段从 4,688 个变为 1,968 个。以下图使用与主图一致的坐标尺度和统计定义。

重新确定字段后，全局非空比例约为 1.01%，即仍有约 98.99% 的结构空白；各类别非空比例约为 3.04%–9.38%。排除该模型后仍存在明显的结构稀疏，而具体程度受字段体系影响。

用于论文时的准确表述

这组结果支持：当前异构 BIM 属性直接展开为固定列时，会形成稀疏表格；构件的属性数量不同，很多字段只由少数模型提供。这些观察为接收可变属性集合的编码方式提供设计动机。

这些图没有比较不同编码器的准确率，也不能单独证明属性级 tokenization 更优。最终清洗、同义合并、类型共享属性补齐后，应按相同定义重新计算论文的最终数值。

统计公式与作图口径

非空比例 = 非空属性出现次数 / (该范围的构件数 N × 观察到的字段并集大小 P)
每构件属性数 = 该构件中有值的末级 key–value 对数量
字段模型支持数 = 含该类构件、且至少一个构件该字段有值的模型数量

A：全局和各类别分别确定字段并集；不做平均比例的简单平均。
B：构件等权；标准 Tukey 箱线图；横轴为 log2，不截断高值。
C：类别—属性组合等权；同一字段在同一模型内出现多次，支持数仍只加 1。
排除 model_6：重新计算行数、字段并集和支持数；三面板与主图使用相同坐标尺度。

这是已观察数据的全体描述统计，不添加没有明确抽样含义的置信区间。输入文件的 SHA-256、完整分组数值和固定原字段体系的敏感性数据均保存在统计 JSON 中。
