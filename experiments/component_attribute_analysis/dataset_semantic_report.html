这些指标怎么读

对象覆盖率看多少构件填写了某项属性；模型覆盖率看多少模型里出现过这项属性；工程量比例只要求工程量集中至少一项有值。高比例不等于信息全部齐全。

semantic 的内容类型

每格为该类构件至少具备一个相应内容字段的比例。类别按字段名初步归类，未全面合并同义字段。“其他自定义属性”更准确指未细分属性，其中也有尺寸、楼层、状态等信息。当前“制造与管理”样本是重复字段名的模板式文字，不能视为真实管理资料。

统计定义与建议
    

  • 统计对象：当前 data/processed 中所有可用模型的图节点。源 IFC 中未进入图的构件不计入对象覆盖率。
    • 

  • 完整属性名：例如 Pset_WallCommon.LoadBearing 表示“墙公共属性集中的承重属性”。整个 Pset 展开成多个末级字段。跨模型同名字段合计，跨构件类别分别统计。
    • 

  • 非空与占位：空字符串、None、NaN、NA/N/A、空容器不计非空；0 和 false 保留。NOTDEFINED 等算已填值，但在“剩余属性数”中剔除。USERDEFINED 不直接视作空值。
    • 

  • 剩余属性数：删除 Name、末级字段名为 Reference 的字段和明确的未定义占位值。其他名称、描述、冗余自定义字段仍可能存在，不把这个数字当作独立信息量。
    • 

  • 重复引用：同一构件多个 Reference 字段的值相同时，除首次外计作重复。只描述当前文本重复，不直接推断模型过拟合。
    • 

  • 原始 IFC 对照：按 GUID 匹配图节点，读取实例、类型继承与部分专用定义、材料集合及空间容器。门扇等专用定义按 IFC 实体类型规范字段名，避免实例名称膨胀字段数。
    • 

  • 当前属性与历史向量：属性输入按当前 semantics_Embed.py 重建，并抽查与 combine_properties 一致；未重新计算 embedding。历史向量若曾复用，无法仅由向量确认当时完整输入。
    • 

  • 单位：长度和工程量沿用各源 IFC 的单位，不把不同单位下的数值混合计算物理量范围。源单位保存在原始 IFC 统计文件的每模型记录中。
    • 

  • 统计范围：这是当前本地数据集的描述统计，不等同于全部 BIM 模型的普遍分布，也不替代下游任务消融验证。


建议优先级
  1. 完善实例与类型属性合并、材料集合解析和类型材料继承，保留来源及覆盖规则。
  2. 将 Name 中的族、类型和实例编号拆分，对重复 Reference 去重；对原文本与规范化文本做消融。
  3. 按任务保留显式尺寸、工程量、承重、外部性和性能属性通道，统一同义字段与单位。来源没有的值需标缺失或由几何计算，不能从字段名称推断。
  4. 用对象覆盖率、模型覆盖率和模型等权覆盖率一起选择稳定特征，避免少数大模型或大量稀有字段主导判断。
