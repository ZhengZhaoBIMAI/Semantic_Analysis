这些类别是本次分析按字段名称进行的初步归类，不是 IFC 官方规定的内容分类。未识别的名称统一落入“其他自定义属性”，因此这个名称更准确应理解为“未细分的其他属性（含软件参数）”。不同语言、带空格的名称和软件专用字段可能没有被归到最合适的一类。

表头想描述什么本次数据中实际出现的例子
名称与引用构件叫什么，如何描述或引用其规格。Name、LongName、Description、Pset_WallCommon.Reference。
分类与用途属于哪种类型，采用哪种组成或开启形式。PredefinedType、CompositionType、OperationType、PartitioningType。
尺寸与工程量构件有多大，面积、体积、跨度等是多少，也包括部分角度参数。OverallHeight、OverallWidth、Qto_ColumnBaseQuantities.Length、Qto_SlabBaseQuantities.NetVolume、Pset_BeamCommon.Span。
材料与构造材料名称和部分构造信息。Material、Materials and Finishes.Structural Material。属性集名字含“钢筋”但仅有 Reference 时，该 Reference 仍归“名称与引用”。
功能与布尔一些常见的功能状态设置。IsExternal、LoadBearing、ExtendToStructure。这里只匹配了部分字段名，并不是全部 true/false 字段都在此列。
性能与安全被规则识别到的热工、耐火、隔声等性能字段。Pset_WallCommon.ThermalTransmittance、Pset_WindowCommon.FireRating。
制造与管理制造商、产品型号、序列号、生产和安装时间、保修与更换成本等字段。Manufacturer、ModelReference、SerialNumber、ProductionYear、InstallationDate、WarrantyStartDate、ReplacementCost。下面说明这些字段的实际内容。
其他自定义属性未被上面规则识别的字段，混合了楼层、偏移、阶段、宿主、标记和软件专用细部参数。Constraints.Level、Constraints.Sill Height、Phasing.Phase Created、Other.Host Id 等。它们有些本来应归尺寸、分类或管理，不能把这一列全当作额外的自定义语义。

制造与管理：字段存在，但实际内容是模板式文字

核对当前统计后，这一类共出现 12 种字段名，全部来自 model_217。它们的取值都是字段名本身，例如 Manufacturer="Manufacturer"。因此表中的非空覆盖率不能代表已经具备真实厂商、安装日期或保修信息。

之前“去掉占位值”的统计只识别 NOTDEFINED、UNKNOWN 等明确未定义词，并没有排除这里的字段名重复文字。因此“非空”与“剩余字段”仍不能直接当作真实有效信息量。
